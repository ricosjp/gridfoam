# Inlet-temperature optimization

```bash
# リポジトリのルートから実行
uv run python -m examples.optimize.inlet_temperature_steady.run --check-grad
```

コードは `run.py` の `main()` から読むと、場の準備・最適化・出力の順に追えます。

| ファイル | 役割 |
| --- | --- |
| `config.yaml` | メッシュ、境界条件、線形ソルバーの設定 |
| `run.py` | 温度方程式、目的関数、Adam の更新ループ |
| `gradient_check.py` | 任意で実行する有限差分との勾配比較 |
| `output.py` | 評価レコード、CSV 保存、履歴・スライス描画 |

`outlet_temperature_loss()` が入口条件の適用から求解・loss 計算までを担当します。
毎回ゼロ初期値から解くため、呼び出し側で温度場をリセットする必要はありません。

一様流 `U = [1, 0, 0]` を与え、定常移流拡散方程式を解いて入口温度を
最適化するスカラー輸送の例です。流れ場自体の反復計算や熱との連成は行いません。
`transport.nu` の値を、この例ではスカラー拡散係数 `alpha` として使います。

上下壁は **`T=0` の固定温度境界**、出口は温度勾配ゼロ、内部熱源はありません。
流体は壁へ熱を失いながら下流へ進むため、流れ方向・幅方向に温度分布ができます。
速度の壁境界は slip のままです。
出口に隣接するセルの温度を算術平均し、目標値 `0.004` との二乗誤差を
最小化します。これは出口面の面積や流量による加重平均ではありません。

スライスの色範囲は `output.py` の `T_FIELD_CLIM = (0.0, 1.30)` に固定しています。
過去の冷却壁の画像と同じ範囲で、入口から出口への温度低下を表示します。
温度 `2.0` など、この範囲外の結果は色が飽和します。別の条件で使う場合は
この定数を変更してください。VTU には表示範囲によらず元の温度値を保存します。

既定の Adam は100回更新しますが、最適化の収束を保証する停止条件ではありません。
初期値は `0.2`、学習率は `0.1` です。`--n-opt` と `--lr` で調整できます。

`feature/adjoint_for_algorithms` の古い例では、温度に指定した `slip` が
実装の不具合により固定温度ゼロとして動作していました。この例は同じ冷却条件を
明示的な `dirichlet` で再現します。

CSV の `step=0` は初期評価、`step=n` は n 回更新した後の評価です。
入口温度・出口温度・loss は同じ評価から記録し、最終行と最終 VTU が対応します。
出力先は `config.yaml` の出力ディレクトリ以下の
`bicgstab-adjoint-0.2/`（既定値）です。
ファイル名の接頭辞には YAML の `output.base_name` を使います
（既定値：`inlet_temperature_steady`）。

既定の `adjoint` は線形系の随伴を使います。温度の線形ソルバーが未収束なら
処理を中断します。比較用 `--grad-mode unrolled` は Krylov 反復を直接微分するため、
主計算が収束しても勾配が不安定になる場合があります。このモードでは開始前に
有限差分との勾配検証を必ず行い、不一致なら最適化を中断します。
