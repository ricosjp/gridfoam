# Transient inlet-temperature optimization

リポジトリのルートから実行します。

```bash
uv run python -m examples.optimize.inlet_temperature_transient.run --check-grad
# 更新回数・物理時間ステップ数・学習率を変更する場合
uv run python -m examples.optimize.inlet_temperature_transient.run --n-opt 40 --n-time 8 --lr 0.1
```

コードは `run.py` の `main()` から読むと、場の準備・最適化・出力の順に追えます。
定常の入口温度最適化と同じ物理（指定流れ・冷却壁）で、時間微分を含む
スカラー輸送を短い軌跡として展開します。

| ファイル | 役割 |
| --- | --- |
| `config.yaml` | メッシュ、境界条件、線形ソルバーの設定 |
| `run.py` | 物理時間ステップの展開、目的関数、Adam の更新ループ |
| `output.py` | 評価レコード、CSV 保存、履歴・スライス描画 |

`PisoStepMap` は圧力—速度場だけを運び、エネルギー方程式は含みません。
この例は `algorithm: manual` の上で
`ddt(T) + div(phi, T) - laplacian(alpha, T) = 0` を解き、実行した有限
ステップ列の autograd graph を残します。各線形求解の微分は既定で暗黙随伴です。
`state.checkpoint()` を学習ステップの間に挟む checkpoint–recompute 随伴では
ありません。ステップ数を増やすとメモリと計算時間が線形に増えます。

一様流 `U = [1, 0, 0]` を与え、入口温度を最適化するスカラー輸送の例です。
流れ場自体の反復計算や熱との連成は行いません。
`transport.nu` の値を、この例ではスカラー拡散係数 `alpha` として使います。

上下壁は **`T=0` の固定温度境界**、出口は温度勾配ゼロ、内部熱源はありません。
既定の `deltaT = 0.25` と `--n-time 8` で、流路の対流時間（長さ 2 m /
速度 1 m/s）と同程度の物理時間になります。出口に隣接するセルの温度を
算術平均し、目標値 `0.004` との二乗誤差を最小化します。これは出口面の
面積や流量による加重平均ではありません。

スライスの色範囲は `output.py` の `T_FIELD_CLIM = (0.0, 1.30)` に固定しています。
温度がこの範囲外の結果は色が飽和します。VTU には表示範囲によらず元の温度値を
保存します。

既定の Adam は 20 回更新します。初期値は `0.2`、学習率は `0.1` です。
`--n-opt` と `--lr` で調整できます。有限時間なので、同じ目標でも定常例より
入口温度を上げる必要があります。熱が出口へ届く前に壁で失われるためです。

CSV の `step=0` は初期評価、`step=n` は n 回更新した後の評価です。
入口温度・出口温度・loss は同じ評価から記録し、最終行と最終 VTU が対応します。
出力先は `config.yaml` の出力ディレクトリ以下の
`bicgstab-adjoint-0.2/`（既定値）です。

既定の `adjoint` は各時間ステップの線形系随伴を使います。温度の線形ソルバーが
未収束なら処理を中断します。比較用 `--grad-mode unrolled` は Krylov 反復を
直接微分するため、主計算が収束しても勾配が不安定になる場合があります。
このモードでは開始前に有限差分との勾配検証を必ず行い、不一致なら最適化を
中断します。
